# BIATHLON TV

Мобильное расписание просмотра биатлона с эфирами, повторами и записями. В интерфейсе время отображается по Москве. Российские и международные результаты и зачёты открываются отдельно от ленты эфиров.

Сейчас доступны парсер сохранённой телепрограммы и ручной сбор сеток пяти каналов «Матча». Для запуска нужен Python 3.11 или новее.

```powershell
python -m pip install -r requirements.txt
python -m collectors.match_tv tests/fixtures/match/2026-11-28.html --source-url "https://matchtv.ru/biathlon/live?date=28-11-2026"
python -m unittest discover -s tests -v
```

Парсер выводит JSON со временем показов в UTC. Тип показа без явной пометки в строке остаётся `unknown`.

Чтобы вручную собрать телесетки пяти каналов на ближайшие семь дней, запустите:

```powershell
python -m collectors.match_guide
```

Для одного дня укажите `--start YYYY-MM-DD --days 1`. Команда выводит показы, ошибки источника и ещё не опубликованные дни в JSON. Если хотя бы одна страница недоступна, код выхода равен 1, а успешно прочитанные показы остаются в выводе.

Чтобы собрать данные для приложения, запустите:

```powershell
python -m collectors.schedule --out data
```

Команда группирует показы одной гонки в событие, а выпуски программы «Биатлон с Дмитрием Губерниевым» — в событие `show` по неделям и записывает `data/schedule.json` и `data/status.json`. Показы с неясным названием попадают в `unmatched`. Если хотя бы одна страница недоступна, прежний `schedule.json` сохраняется, а `status.json` отмечает устаревание. Ещё не опубликованные дни ошибкой не считаются и перечислены в `unpublished`.

Сбор запускается автоматически через GitHub Actions ([collect.yml](.github/workflows/collect.yml)) каждый день в 07:15 МСК. Данные собираются в воскресенье и понедельник, а в остальные дни — только если в сетке текущей недели остались пробелы или источник был недоступен. Свежие `data/schedule.json` и `data/status.json` коммитятся в репозиторий. Ручной запуск из вкладки Actions собирает данные всегда. Тот же пропуск можно проверить локально флагом `--only-when-due`.
