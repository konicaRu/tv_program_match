# BIATHLON TV

Мобильное расписание просмотра биатлона с эфирами, повторами и записями. В интерфейсе время отображается по Москве. Российские и международные результаты и зачёты открываются отдельно от ленты эфиров.

Сейчас готовы сбор телепрограммы пяти каналов «Матча» и расписаний Okko и мобильное приложение с лентой эфиров. Показы группируются по гонкам и обновляются автоматически через GitHub Actions. Приложение публикуется на GitHub Pages: https://konicaru.github.io/tv_program_match/ Для запуска нужен Python 3.11 или новее.

```powershell
python -m pip install -r requirements.txt
python -m collectors.match_tv tests/fixtures/match/2026-11-28.html --source-url "https://matchtv.ru/biathlon/live?date=28-11-2026"
python -m unittest discover -s tests -v
```

Парсер выводит JSON со временем показов в UTC. Тип показа без явной пометки в строке остаётся `unknown`.

Чтобы вручную собрать телесетки пяти каналов на ближайшие семь дней, запустите:

```powershell
python -m collectors.match_guide
```

Для одного дня укажите `--start YYYY-MM-DD --days 1`. Команда выводит показы, ошибки источника и ещё не опубликованные дни в JSON. Если хотя бы одна страница недоступна, код выхода равен 1, а успешно прочитанные показы остаются в выводе.

Чтобы собрать данные для приложения, запустите:

```powershell
python -m collectors.schedule
```

Команда группирует показы одной гонки в событие, а выпуски программы «Биатлон с Дмитрием Губерниевым» — в событие `show` по неделям и записывает `public/data/schedule.json` и `public/data/status.json`. Показы с неясным названием попадают в `unmatched`. Если хотя бы одна страница недоступна, прежний `schedule.json` сохраняется, а `status.json` отмечает устаревание. Ещё не опубликованные дни ошибкой не считаются и перечислены в `unpublished`.

Эфиры Okko берутся из расписаний-картинок в официальном Telegram-канале [Okko Зимний Спорт](https://t.me/okkowintersport): `collectors/okko_telegram.py` распознаёт их через Tesseract и оставляет только строки с понятными датой, временем, дисциплиной и полом. Для локального запуска нужен Tesseract с русским языком (`tesseract-ocr-rus`); тесты распознавания без него пропускаются.

Сбор запускается автоматически через GitHub Actions ([collect.yml](.github/workflows/collect.yml)) дважды в день, в 07:15 и 19:15 МСК: Okko публикует расписание этапа в середине недели. Если эфиры и состояние источников не изменились, ничего не коммитится и не публикуется. Иначе свежие `public/data/schedule.json` и `public/data/status.json` коммитятся в репозиторий, после чего приложение публикуется заново.

Приложение написано на React, Vite и TypeScript. Для запуска нужен Node.js 22 или новее:

```powershell
npm install
npm run dev
```

Откройте http://localhost:5173/tv_program_match/. Лента показывает дни с эфирами, карточку гонки или программы со всеми показами и повторами и предупреждает об устаревших данных. Время всегда московское. Проверки: `npm test` (функции ленты), `npm run build`, затем `npm run test:e2e` (сценарии Playwright на ширине 360, 390 и 430 px и работа собранного приложения без сети; перед первым запуском `npx playwright install chromium`).

Публикацию выполняет [deploy.yml](.github/workflows/deploy.yml): при каждом пуше в `main` и после обновления данных он прогоняет тесты и сценарии Playwright, собирает приложение и выкладывает его на GitHub Pages.
