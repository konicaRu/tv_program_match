У «Матча» прямой HTML биатлонного раздела содержит блоки `broadcast__item`, идентификатор канала и Unix-метки начала и окончания. В общей видеоподборке используется `publishDate`, которую нельзя считать временем эфира без строки телесетки. Для повторов проверяем соседние календарные сутки, включая ночные показы.

Официальный телегид принимает параметр `date=YYYY-MM-DD`. Для сверки даты и канала сборщик использует выбранную дату и заголовок страницы. Фикстуры сохраняют часы всех передач дня и точные заголовки биатлонных показов.
