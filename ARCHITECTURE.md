# Архитектура BIATHLON TV

Мобильное расписание трансляций биатлона: эфиры и повторы «Матча» и Okko по московскому времени, без результатов в ленте. Сервера нет: данные собирает GitHub Actions, приложение — статическая PWA на GitHub Pages.

## Поток данных

```text
matchtv.ru/tvguide/<канал>?date=…  ─┐  (5 каналов × 7 дней)
                                     ├─ collectors/schedule.py ─► public/data/schedule.json
t.me/s/okkowintersport (картинки) ──┘   (группировка по гонкам)    public/data/status.json
            │ OCR Tesseract                                             │
                                                                        ▼
        .github/workflows/collect.yml (07:15 и 19:15 МСК)       коммит только при изменениях
                                                                        │ вызывает
                                                                        ▼
        .github/workflows/deploy.yml: тесты, Playwright, сборка ─► GitHub Pages (PWA)
                                                                        │
                                       https://konicaru.github.io/tv_program_match/
```

## Компоненты

| Файл | Что делает |
|---|---|
| `collectors/match_guide.py` | Дневные сетки «Матч ТВ», «Страны», «Арены», «Игры», «Премьера». Берёт строки «Биатлон.» и программу «Биатлон с Дмитрием Губерниевым». Показы после полуночи, пометки «прямая трансляция» и «повтор», повтор по совпадению названия в пределах суток. Неопубликованный день (`--availability-not-available` в календаре) — не ошибка, а `unpublished`. |
| `collectors/match_tv.py` | Разбор раздела matchtv.ru/biathlon/live (сохранённая страница). Общий тип `Broadcast`. Кандидат во второй официальный источник «Матча». |
| `collectors/okko_telegram.py` | Официальный канал Okko Зимний Спорт: посты со словами «расписание» и «биатлон», картинки → OCR (только белый текст, увеличение ×3, порог 170, `--psm 4`). Строка берётся, только если ясны дата, время, дисциплина и пол; при нечитаемой дате строки под ней отбрасываются. Новый пост о той же гонке и дне заменяет старый. Ссылка на пост — подтверждение. |
| `collectors/schedule.py` | Разбор названия на соревнование, дисциплину, пол и категорию; событие = гонка (показы дальше трёх дней — новый этап) или недельный выпуск программы. Атомарная запись JSON; при ошибке источника прежний `schedule.json` остаётся, `status.json` получает `stale`. Без изменений ничего не пишет. |
| `src/lib/schedule.ts` | Типы данных, группировка по московским дням (событие видно в каждый день, когда есть показ), подписи, состояния «Сейчас»/«Завершено» только при известном окончании. |
| `src/App.tsx`, `src/styles.css` | Лента: полоса дней, карточки с временем, пометками и каналами, раскрытие «Время трансляций», предупреждение об устаревании. |
| `vite.config.ts` | База `/tv_program_match/`, манифест и service worker (`vite-plugin-pwa`); данные кешируются «сначала сеть» по литеральному шаблону (функция в `sw.js` не видит переменных конфига). |

## Модель данных

- `schedule.json`: `events[]` (`event_id`, `kind: race|show`, `title`, `competition`, `discipline`, `gender`, `category`, `broadcasts[]`) и `unmatched[]` — показы, которые не удалось уверенно отнести к гонке.
- `broadcast`: `broadcast_id`, `platform` (`MATCH`/`OKKO`), `channel`, `title` (как в источнике), `type` (`live|replay|unknown|…`), `start_utc`, `end_utc`, `url`, `source_url`, `verified_at`.
- `status.json`: `checked_at`, `last_success`, `stale`, `errors{url: текст}`, `unpublished[]`.
- Время в данных — UTC, в интерфейсе — Europe/Moscow через `Intl`.

## Проверки

- Python: `python -m unittest discover -s tests` (на реальных сохранённых страницах «Матча» и постах Okko; тест OCR — только где установлен Tesseract).
- Приложение: `npm test` (vitest, в том числе в чужом часовом поясе), `npm run build`, `npm run test:e2e` (Playwright на 360/390/430 px и работа собранного приложения без сети).

## План: резервные источники

Цель — лента не должна пустеть, если один источник сломался или сменил формат.

1. **Раздельное хранение по источникам.** Каждый источник хранит свои последние удачные показы; лента собирается из всех; `status.json` показывает свежесть по каждому. Сбой одного не блокирует остальные (сейчас любой сбой оставляет весь `schedule.json` прежним).
2. **«Матч»:** второй официальный источник — раздел matchtv.ru/biathlon/live (парсер есть). Независимые телепрограммы и EPG-фиды — только для сверки или с пометкой «не подтверждено», по решению пользователя (конституция требует подтверждения «Матчем» или Okko).
3. **Okko, только бесплатно:** новости okko.tv/media (доступны из-за рубежа, время в тексте, список статей в `sitemap_media_news.xml`), другие официальные аккаунты (@okkosport, ВКонтакте, MAX). Страница этапа на okko.sport заполняется внутренним API и вне России пустая; бесплатный доступ — домашний компьютер пользователя как self-hosted раннер GitHub Actions с Playwright (без входа, без внутреннего API, без обхода проверок) или бесплатная квота Yandex Cloud.
4. Дальше: адаптеры статистики IBU и российских соревнований (раздел 10 плана), фильтры, нижнее меню, `overrides.json` для ручных поправок.

Команды запуска описаны в README, правила работы с данными — в [конституции проекта](docs/constitution.md), проверка источников — в [docs/SOURCES.md](docs/SOURCES.md).
