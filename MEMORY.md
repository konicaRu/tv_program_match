# Контекст проекта

## Статус

Добавлен ручной сбор дневных сеток пяти каналов. На официальной сетке за 28 ноября проверены восемь показов, включая четыре повтора. [Результаты проверки источников](docs/SOURCES.md).

## Решения

- Рабочий сезон MVP — 2026/27. Проверять «Матч ТВ», «Матч Страна», «Матч Арена», «Матч Игра» и «Матч Премьер». Линейку «Матч Футбол» исключить.
- Телепрограмму смотреть на ближайшие семь дней, основной день проверки — понедельник по МСК. Воскресенье подходит для предварительной проверки опубликованной сетки. После сбора доступных эфиров и повторов мониторинг на эту неделю завершать.

- MVP включает российские результаты и отдельные мужской и женский зачёты, а также статистику IBU. Лента эфиров без спойлеров.
- Интерфейс и документы на русском. Идентификаторы кода и полей данных на английском.
- При сохранении контекста, коммите и пуше сверять README с проектом и обновлять его по фактическим изменениям. Оформление README выбрать после завершения проекта.
- Использовать Karpathy и Superpowers по задаче, проверять сценарии интерфейса через Playwright. Пушить по команде `git save` или прямой просьбе.
