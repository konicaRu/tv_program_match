# Контекст проекта

## Статус

Сбор работает автоматически: GitHub Actions (`collect.yml`) коммитит `public/data/schedule.json` и `public/data/status.json`. Мобильное приложение готово локально, на GitHub Pages ещё не опубликовано. Первый запуск 25.11.2026 дал пять событий и 19 показов на 28–29.11: четыре гонки Кубка Содружества и программу Губерниева. Пользователь сверил выходные: утром прямые эфиры на «Матч ТВ» и «Арене», вечером повторы на «Стране». Сетка «Матча» публикуется по воскресенье текущей недели, следующие дни помечаются как неопубликованные. [Результаты проверки источников](docs/SOURCES.md).

## Решения

- Рабочий сезон MVP — 2026/27. Проверять «Матч ТВ», «Матч Страна», «Матч Арена», «Матч Игра» и «Матч Премьер». Линейку «Матч Футбол» исключить.
- Телепрограмму смотреть на ближайшие семь дней, основной день проверки — понедельник по МСК. Воскресенье подходит для предварительной проверки опубликованной сетки. После сбора доступных эфиров и повторов мониторинг на эту неделю завершать. В Actions это правило `--only-when-due`: воскресенье и понедельник всегда, в остальные дни только при пробелах до ближайшего воскресенья или сбое источника.
- В ленту входит программа «Биатлон с Дмитрием Губерниевым» (обычно воскресенье, 09:45 МСК на «Матч ТВ» и «Арене», повтор вечером на «Стране»). Первый показ недели остаётся `unknown`, более поздний в течение суток — `replay`.
- MVP включает российские результаты и отдельные мужской и женский зачёты, а также статистику IBU. Лента эфиров без спойлеров.
- Интерфейс и документы на русском. Идентификаторы кода и полей данных на английском.
- При сохранении контекста, коммите и пуше сверять README с проектом и обновлять его по фактическим изменениям. Оформление README выбрать после завершения проекта.
- Использовать Karpathy и Superpowers по задаче, проверять сценарии интерфейса через Playwright. Пушить по команде `git save` или прямой просьбе.

## Открытые вопросы

- Следующий согласуемый шаг — публикация на GitHub Pages (`deploy.yml`, настройка Pages в репозитории), затем проверка установки на телефон и работы без сети. `overrides.json` — когда накопятся реальные случаи.
- Нижнее меню «Эфиры / Зачёт / Результаты / Участники» и фильтры ленты ещё не сделаны.
- Событие = соревнование + дисциплина + пол, показы дальше трёх дней от первого относятся к новому событию. Проверить на реальном Кубке мира.
- Доступность программы Okko и способ регулярного получения официальной статистики сезона 2026/27 остаются открытыми.
