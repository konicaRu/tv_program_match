# Контекст проекта

## Статус

Сбор работает автоматически: GitHub Actions (`collect.yml`) коммитит `public/data/schedule.json` и `public/data/status.json`. Приложение опубликовано на https://konicaru.github.io/tv_program_match/ и обновляется после каждого сбора. Работа без сети проверена сценарием Playwright и на живом сайте (расписание в кеше service worker). Первый запуск 25.11.2026 дал пять событий и 19 показов на 28–29.11: четыре гонки Кубка Содружества и программу Губерниева. Пользователь сверил выходные: утром прямые эфиры на «Матч ТВ» и «Арене», вечером повторы на «Стране». Сетка «Матча» публикуется по воскресенье текущей недели, следующие дни помечаются как неопубликованные. [Результаты проверки источников](docs/SOURCES.md).

## Решения

- Рабочий сезон MVP — 2026/27. Проверять «Матч ТВ», «Матч Страна», «Матч Арена», «Матч Игра» и «Матч Премьер». Линейку «Матч Футбол» исключить.
- Телепрограмму смотреть на ближайшие семь дней. С 25.11.2026 сбор идёт дважды в день (07:15 и 19:15 МСК), потому что Okko публикует расписание этапа в середине недели; коммит и публикация только при изменении эфиров или состояния источников. Правило «воскресенье и понедельник» (`--only-when-due`) убрано.
- Okko берём из официального Telegram-канала @okkowintersport: расписание этапа — картинка, читается OCR (Tesseract). Неясные строки пропускаются. Внутренний API okko.sport не трогаем, защиту от ботов не обходим.
- Нужны резервные источники и для «Матча», и для Okko (25.11.2026). Для Okko — только бесплатные варианты.
- В ленту входит программа «Биатлон с Дмитрием Губерниевым» (обычно воскресенье, 09:45 МСК на «Матч ТВ» и «Арене», повтор вечером на «Стране»). Первый показ недели остаётся `unknown`, более поздний в течение суток — `replay`.
- MVP включает российские результаты и отдельные мужской и женский зачёты, а также статистику IBU. Лента эфиров без спойлеров.
- Интерфейс и документы на русском. Идентификаторы кода и полей данных на английском.
- При сохранении контекста, коммите и пуше сверять README с проектом и обновлять его по фактическим изменениям. Оформление README выбрать после завершения проекта.
- Использовать Karpathy и Superpowers по задаче, проверять сценарии интерфейса через Playwright. Пушить по команде `git save` или прямой просьбе.

## Открытые вопросы

- **Следующий шаг (26.11.2026): резервные источники**, план в ARCHITECTURE.md «План: резервные источники». Начать с раздельного хранения по источникам, затем matchtv.ru/biathlon/live как второй источник «Матча», новости okko.tv (sitemap) и @okkosport/ВКонтакте для Okko.
- Решить с пользователем: независимые телепрограммы «Матча» — только сверка или показ с пометкой «не подтверждено».
- Okko с российским IP бесплатно: домашний ПК как self-hosted раннер (если включён утром и вечером) или Yandex Cloud free tier. Пользователь ещё не выбрал.
- Пользователю проверить установку на телефон (Android Chrome: меню → «Установить приложение»).
- Следующие кандидаты: нижнее меню и разделы «Зачёт / Результаты / Участники» (нужен источник официальной статистики), фильтры ленты, `overrides.json` — когда накопятся реальные случаи (например, ошибки на картинках Okko).
- Событие = соревнование + дисциплина + пол, показы дальше трёх дней от первого относятся к новому событию. Проверить на реальном Кубке мира.
- Способ регулярного получения официальной статистики сезона 2026/27 остаётся открытым.
- Распознавание картинок Okko проверено на двух расписаниях; следить, не сломается ли на новых шаблонах (Чемпионат мира, другие оформления).
